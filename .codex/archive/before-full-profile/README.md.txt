# Aarya Avinash portfolio

A personal portfolio built with Vite, TypeScript, Tailwind CSS, GSAP ScrollTrigger, and Lenis. The layout and motion take inspiration from the Marcus Vane reference; the visible content now presents Aarya's work.

```sh
npm ci
npm run dev
```

`npm run build` typechecks and produces `dist/`. `node tools/check-voices.mjs` checks the interactive focus selector. React Bits `AnimatedContent` and `Counter` animate the GitHub snapshot as it nears view.

Content sources: [Aarya's GitHub profile](https://github.com/aaryaavinash) and the [Aequarch Esports repository](https://github.com/aaryaavinash/Aequarch-Esports). The contact email was supplied by Aarya. The hero uses Aarya's public GitHub profile photo; project covers are local illustrative SVGs. The profile counts are a snapshot from October 2026 and link to live GitHub for current values.

Project notes: [.codex/README.md](.codex/README.md), [.codex/design.md](.codex/design.md), [.codex/animation.md](.codex/animation.md), and [.codex/prd.md](.codex/prd.md). Original source before personalization is preserved as disabled comments in `.codex/archive/before-personalization/`.
