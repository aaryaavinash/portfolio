# Aarya Avinash portfolio

A personal portfolio built with Vite, TypeScript, Tailwind CSS, GSAP ScrollTrigger, Lenis, and small React islands. The cinematic layout is inspired by the Marcus Vane reference; the visible content is about Aarya.

```sh
npm ci
npm run dev
```

`npm run build` typechecks and produces `dist/`. `npm run preview` serves the build. Focused checks: `node tools/check-voices.mjs` and `node tools/check-contributions.mjs`.

The page presents Aarya as a student, developer, founder of [Zyrix Dev](https://dev.zyrix.qzz.io), video editor, graphic designer, forex/crypto trader, and gamer. Featured work links to [Aequarch Esports](https://github.com/aaryaavinash/Aequarch-Esports) and Zyrix Dev.
